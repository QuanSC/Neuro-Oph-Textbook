# Neuro-Ophthalmology: An Interactive Textbook

**Author:** Steven C. Quan, OD, FAAO
Assistant Professor of Ophthalmology and Visual Science, University of Chicago

This is an independent educational work by the author. It is not an official publication of, or endorsed by, the University of Chicago. Views are the author's own.

## About

Twenty-two interactive study modules covering the core of neuro-ophthalmology, from anatomy and the clinical exam through optic neuropathies, motility, nystagmus, vascular and inflammatory disease, trauma, headache, vestibular disorders, landmark trials and pediatric neuro-ophthalmology.

Each module includes an interactive tool (simulators, lesion maps, calculators or decision pathways), case vignettes, clinical pearls, a self-quiz and a "where the numbers come from" section that traces figures to their sources.

**Start here:** https://quansc.github.io/Neuro-Oph-Textbook/

## Technical notes

- Plain HTML, CSS and JavaScript in single files; no external libraries, fonts or tracking.
- Works on phones and desktops, in light and dark mode, and offline once downloaded.
- Keep all files in the same folder so links between modules work.

## Disclaimer

For educational purposes only; not medical advice. Clinical decisions should follow current guidelines and institutional protocols. Cases are fictional teaching composites. Evidence changes; each module lists its sources and the hub lists items still being verified.

Content was drafted with AI assistance (Claude, Anthropic) and curated by the author.
